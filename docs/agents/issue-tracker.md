# Issue tracker

Development work is tracked in the **Insieme** project in the **Blackspace** Linear workspace.

- Create actionable work as Linear issues in the Insieme project.
- Keep issue titles outcome-focused and include acceptance criteria in the description.
- Use the project roadmap document for prioritization; use repository `ROADMAP.md` as the version-controlled mirror.
- Reference the Linear issue identifier in commits and pull requests when an issue exists.
- Update or close the Linear issue when the corresponding change ships.

Repository: `https://github.com/myverp/insieme`
